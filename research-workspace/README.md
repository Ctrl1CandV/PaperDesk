# 跨电脑研究工作区

此目录保存真实探索数据，随 Git 传递。请在私人仓库中使用。它不属于公开教学内容或测试样例，也不会打包到前端静态资源。

正常使用 `npm start` 或 `npm run dev`。网页启动时，会把当前浏览器已有探索迁入本地项目文件，并载入另一台电脑拉取的探索。之后保存方向、工作稿、摘录、文献关联和选文文件会更新本地项目工作区。笔记列表、阅读标记、AI 对话数据库、原文材料和模型密钥不在此目录。

“已保存到项目”表示磁盘写入完成，仍需要 Git 提交和推送才能到另一台电脑。换电脑之前：

```text
git add research-workspace
git commit -m "Update research workspace"
git push
```

另一台电脑先拉取，再启动平台：

```text
git pull
npm ci
npm run build
npm start
```

前端和后端代码未变时无需重复安装、构建。平台运行中拉取数据后，可以点击页面的同步按钮或切回浏览器触发载入。

`explorations/<探索UUID>/<内容SHA256>.json` 是不可变修订，包含完整探索及其父修订；删除以空记录修订表示。Git 可以同时保留两台电脑新增的文件；页面发现同一方向的并行修订时会提供比较和选择，不按时间戳猜测胜者。不要手动删除历史文件、修改 hash 文件名或编辑文件正文；在页面中修改、恢复或解决冲突会追加新修订。

首次迁移必须用原来保存探索的浏览器及固定地址 `http://127.0.0.1:4173` 打开新版一次。全新浏览器无法读取另一个浏览器的 IndexedDB；截图也不能恢复完整工作稿。请先看到已保存到项目，再提交本目录中的 JSON。

“清除本地记录”会暂停当前浏览器的项目同步，不清除此目录。要继续载入，点击“恢复项目同步”。要在各电脑删除某个方向，请在探索页删除并同步、提交其新增修订。历史文件仍可从 Git 恢复；删除不等于从 Git 历史中彻底清除。
