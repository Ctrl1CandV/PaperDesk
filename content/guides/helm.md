# HELM：把“模型表现”变成一组能够解释的测量

《Holistic Evaluation of Language Models》面对的是语言模型研究中的一个基础困难：模型可以用于许多任务，但已有评测分散在不同数据、提示和指标中，读者很难形成整体认识。HELM 提出一套更全面的评价框架，并在当时的30个模型上进行大规模测试。它既研究怎样测，也利用测量观察模型表现之间的关系。[原论文 v2](https://arxiv.org/pdf/2211.09110v2)

这篇的价值不在于记住历史榜单。它能帮助你理解，一篇论文所说的“能力”如何经过任务、输入设置和评分方法，才变成实验中的数字。如果前一篇 InstructGPT 讲的是怎样改变模型行为，这篇就接着解释怎样认识这种行为。

## 作者先处理了“各自都测过，却难以比较”的问题

假设两篇论文分别报告了很好的结果：一篇做科学问答，另一篇做摘要。它们显然没有回答同一个问题。即使都做选择题，也可能一个模型经过任务微调，另一个只在提示中看到几个例子；一个直接输出选项字母，另一个逐个计算候选答案的概率。表格里都写“准确率”，测试过程仍可能不同。

这不是纯粹的假设担忧。HELM 作者梳理既有工作时发现，模型的评测覆盖很不均匀，甚至有重要模型在最初论文中没有共同测过的数据集。因此，作者把工作分为三个相连的目标：扩大场景覆盖并明确缺口，在同一场景观察多种要求，以及尽可能统一不同模型参加测试的方式。[作者对研究背景和原则的说明](https://crfm.stanford.edu/2022/11/17/helm.html)

这里的“全面”是主动组织评价范围，不是宣称已经测完一切。先说明任务空间，再说明本次覆盖哪里，未测的地方才不会悄悄变成“模型应该也可以”。

## 从一道真实的选择题看懂评价过程

论文的[图6，PDF 第14页](https://arxiv.org/pdf/2211.09110v2#page=14)使用 MMLU 的一个知识选择题：它询问描述身体保持正常状态的术语，正确选项是 Homeostasis，即稳态。理解评价流程不要求你先会做解剖学题；要留意的是，一条测试样本包含题目、候选答案，以及哪个答案被标为正确。

接下来，通用语言模型怎样参加这道测试？[图7，第15页](https://arxiv.org/pdf/2211.09110v2#page=15)展示了两种适配方式。左边把题目和全部候选项放在一起，让模型续写答案字母；右边把不同候选答案分别接到题目后面，根据模型给予这些文本的概率比较候选。前面的已答示例、提示格式与生成设置，也属于适配的一部分。

于是，一次评价可以连成一条完整过程：**选定场景与样本 → 按规则组织模型输入 → 获得输出或概率 → 用指标评分。** 场景回答“让它做什么”，适配回答“怎样让这个模型做”，指标回答“按什么标准认识结果”。原文图5把这三者连接起来。只要其中一处变化，最终分数就可能改变。

这也是适配值得在方法部分认真阅读的原因。让一个语言模型做选择题，并不是把试卷直接递给一个已经约定好答题规则的人；接口本身就需要设计。统一接口有助比较，但仍不等于每个模型都处于各自最有利的使用条件。

## 七类指标是在表达七种不同要求

HELM 的核心评价尽可能在相同场景同时测量多种指标。先理解它们各自在补充什么，再记名称会更容易。

| 要求 | 在本文中怎样理解 |
|---|---|
| 准确性 | 输出是否符合任务要求；选择题可以判对错，摘要等任务要用相应质量度量，不能把所有分数都理解成答对题数比例 |
| 校准 | 模型给出的预测概率与实际正确频率是否相称 |
| 鲁棒性 | 拼写等输入变化后，表现是否仍稳定 |
| 公平性 | 比较不同群体或相关表述变化下的表现；本文的具体测法只覆盖公平性的一部分 |
| 社会偏见 | 生成内容中是否出现群体关联、代表性等偏差 |
| 毒性 | 输出是否包含相应有害表达，具体由所用检测方法界定 |
| 效率 | 获得这些表现需要多少计算和运行资源 |

这七类对应[原文 §4](https://arxiv.org/pdf/2211.09110v2#page=25)的组织，而不是七个可以无条件相加的分数。公平性、偏见和毒性有联系，却在测不同现象；效率又涉及模型和运行条件。多指标的目的，是让这些差异进入讨论。

其中校准常较陌生。用一个辅助例子说明：如果模型对一批选择题的预测概率都在80%左右，长期看其中约八成正确，才符合这个概率的含义。如果同样说有80%的把握，却经常答错，问题就在概率与实际结果不匹配。这里指预测概率，不是生成一句“我非常有信心”。准确率只计答对多少，校准还检查把握程度是否可靠。[校准研究的定义与背景](https://arxiv.org/abs/1706.04599)

论文设置了16个核心场景，以及26个针对特定能力或风险的场景。前者支持更综合的横向观察，后者便于单独检查特定现象；七类指标并非在所有场景都完整测到。[作者对核心与针对性评价的说明](https://crfm.stanford.edu/2022/11/17/helm.html)

## 实际发现揭示了指标和设置之间的关系

先看准确性与校准。HellaSwag 是常识情境的后续事件选择测试，OpenBookQA 是科学知识问答测试。在论文的模型比较中，HellaSwag 上更高准确性伴随更差校准，OpenBookQA 上则观察到同向改善；这种关系也依赖适配方式。它说明“多答对一些”与“更可靠地判断自己会不会”需要分别观察。这是跨模型、跨设置的实验关系，不能写成提高准确率必然导致校准变差的因果规律。[原文 §1.2、§8.1](https://arxiv.org/pdf/2211.09110v2#page=6)

再看提示适配。论文报告，在 HellaSwag 上，OPT 175B 采用分开候选且不提供示例的设置时，准确率为79.1%；采用联合候选并提供五个示例的设置时，为30.2%。同一模型出现巨大差异，使前面关于适配的讨论有了实际分量。这里候选组织和示例数量同时变了，不能只得出“给例子反而更差”。[原文主要发现第23项，PDF 第9页](https://arxiv.org/pdf/2211.09110v2#page=9)

另一个发现涉及规模与成本。在同一模型家族中，更大规模通常带来更高准确性和更多计算开销；跨家族比较时，训练方式等差异同时存在，参数量并不足以直接确定下游排名。对你建立知识体系而言，这接回了 InstructGPT 中的重要区分：模型规模是一种设计选择，训练目标和使用方法也在塑造表现。[原文 §1.2 的效率与模型规模讨论](https://arxiv.org/pdf/2211.09110v2#page=7)

阅读[图24，PDF 第48页](https://arxiv.org/pdf/2211.09110v2#page=48)时，可以沿着作者的工作方式再看一遍：各小图以准确性为横轴，以另外一种指标为纵轴；颜色区分场景。校准误差越低越好，而鲁棒性得分越高越好，因此不能把所有图中的“向上”都读成改善。把这些点放在一起，是为了观察哪些关系比较一致、哪些明显依赖任务。

## 评价研究的贡献，是让原先含糊的比较变得可解释

HELM 没有因为提出了七类指标，就自动解决所有模型评价问题。它的重要贡献是把比较前的选择显露出来，并用同一套组织方式产生一组可以讨论的结果。研究因此不只得到“谁更高”，还能够追问不同指标何时一致、何时冲突，以及结果对输入方式有多敏感。

其范围也需要放回当时：本版主要覆盖英语和所选任务，模型集合属于历史切片。[原文 §1.1](https://arxiv.org/pdf/2211.09110v2#page=3)

另外，训练数据是否包含测试材料并不总能查清，固定提示也未必体现每个模型的最好能力。这些限制决定结果该怎样使用，而不是取消评价本身的价值。[原文 §11，PDF 第81页](https://arxiv.org/pdf/2211.09110v2#page=81)

对后续研究而言，你可以从中学习一种工作方式：先把希望改善的能力表达成可观察的任务与条件，再决定什么证据足以支持结论。暂时不必设计一个新榜单；读下一篇方法论文时，能看出其提升发生在什么评价条件里，已经能让文献之间的比较更准确。

## 留下一条能够再次使用的认识

可以把一项感兴趣的结果写成这样一条关系：在什么任务里，模型经过怎样的适配，哪个指标发生了什么变化。这个表达比孤立记住一个分数更容易在以后比较论文时使用。它是可选的积累方式，不需要填表或提交作业。

## 哪些原文值得亲自读

当前建立评价框架的认识，可以先以导读为主。最值得亲自对照的是[图5–7及 §2.1–2.2，PDF 第14–15页](https://arxiv.org/pdf/2211.09110v2#page=14)：沿一道选择题看场景、模型输入和评分接口怎样衔接，特别留意图7左右两种候选答案组织方式。它能把抽象的评价术语对应到真实研究设计。

以后想理解结果之间的关系，再看[图24及正文解释，PDF 第48页](https://arxiv.org/pdf/2211.09110v2#page=48)，先确认坐标、指标方向与场景颜色，再看关系。准备进一步研究实验设计时，带着一个具体场景进入 §7 的适配与对应的 §8 结果；无需先记住所有模型、数据集或读完全部指标定义。

完整模型清单、暂时无关的场景和附录可以留到确有比较或复现需求时再读。正文引用用于查证，并不要求这轮逐条打开。

**范围。** 本文是评价主线导读，固定 arXiv 2211.09110v2，不逐项复述全部场景和附录。图5–7与图24已经观看；未复现实验。原文 §2.3 示例指标表用于说明接口，不作为本导读的实测结果。历史数字不代表当前模型榜单，与其他两篇的联系是编者提供的阅读组织。
