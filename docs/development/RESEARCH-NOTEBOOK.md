# 研究工作稿与按方向交付文献

每个研究方向有一份**研究工作稿**：一份读者和 AI 都能修改的 Markdown 文档。阅读、思考和讨论中的收获持续写进来；读者认为方向可以做实验、写论文时，导出即是论文项目的起始文件。研究对象仍是原来的 Exploration，数据仍是 `research.notebook`；没有新增云同步、账号或第二套研究状态。

## 设计取舍

- **从第一天起就是论文项目的形状。** 工作稿默认按六个二级标题组织，分别对应论文的一部分。标题只是建议，读者可以改名、删除或新增；空小节里的 `<!-- 提示 -->` 在页面上显示为灰色的“待补充”，导出和交给 AI 时去掉。

  | 小节 | 写什么 | 将来用作 |
  |---|---|---|
  | 问题与动机 | 为什么值得做，现有做法卡在哪里 | 引言 |
  | 已知 | 文献已经说明了什么，每条附出处 | 相关工作 |
  | 判断与假设 | 目前的看法和要检验的假设，注明依据强弱 | 方法动机 |
  | 未解决的问题 | 还需要阅读或实验回答的问题 | 研究问题 |
  | 实验设想 | 最小可行实验：数据、基线、指标、预期与反证条件 | 实验计划 |
  | 阶段记录 | 每行一条：日期 · 收获或转变 | 项目日志 |

- **阶段性收获单独可见。** “阶段记录”小节里形如 `- YYYY-MM-DD · 内容` 的行会被解析出来：方向页侧栏显示最近几条，探索列表显示最近一条。数据只有工作稿这一份，侧栏和列表都从它读取。
- **两种写法，都是新版本。** 读者直接编辑或“记一笔”；AI 只在读者输入 `/记录`（或点“让 AI 整理”后发送）时写入。每一版可带一句“这次改了什么”，历史里可以与上一版逐行对比。
- **引导保持安静。** 方向页主栏只有工作稿和摘录；阶段、阶段记录、相关文献、选文文件在一个侧栏里；导出、添加摘录等低频操作收在“⋯”菜单。

## 使用方式

- **开始**：用 `/方向` 建立方向时，AI 用同一轮讨论写出工作稿第一版（问题、认识、候选、不确定之处和一条“建立方向”的阶段记录），作者记为 AI。已有方向还没有工作稿时，点“按这个骨架开始写”，编辑框会先填入骨架以及方向里已有的认识、候选、暂缓、范围与约束、未知和已确认的决定，读者确认后保存。
- **记一笔**：侧栏“阶段记录”下输入一句话、按回车，即在工作稿“阶段记录”末尾加一行带今天日期的记录并保存为新版本（说明为“记一笔：…”）。第一条会替换未动过的提示。
- **编辑**：主栏右上“编辑”，支持 Markdown、预览、站内导读链接（`/read/导读ID/修订#章节`）、表格与公式；不执行 HTML，不加载远程图片。
- **让 AI 整理**：在同一讨论面板预填 `/记录`，读者可以补充要求再发送。AI 把新内容放进对应小节，保留读者的写法和改过的结构；无依据的内容标〔假设〕或〔待验证〕，“已知”附本轮真实来源的链接；阶段记录只记读者明确表达或讨论中确实达成的进展，日期由服务端提供。普通问答不写入。
- **历史**：点版本信息那一行（“第 N 版 · 作者 · 时间”）打开历史；可选“与上一版对比”逐行查看新增和删除，过长的正文提示分别下载对照。恢复旧版会保存为新的一版，之后的版本保留。
- **导出项目起始文件**：在“⋯”菜单。文件包含：方向标题、核心问题与阶段；“关于这份文件”（各小节对应论文哪一部分、哪些仍是假设、尚未执行任何实验、未授权的行动一律待确认）；工作稿正文（去掉提示）；参考文献（关联、摘录和下一步涉及的本库导读及其固定原文版本）；读者保存的摘录与出处；已生成的选文实施文件列表。它可以直接作为论文仓库的 README 或研究计划继续编写，是私人文件，不进入公开内容包或 Git。
- 编辑期间其他页面或 AI 写入了新版本时，保存会提示比较并保留未保存文本；草稿在站内导航中保留，刷新或关闭前有离开提示，但它不是已保存的记录。

## 数据与 AI 边界

- `research.notebook.versions` 保存连续版本；每版有 `body/author/createdAt`，AI 写入另有 `sourceTurnId`，恢复另有 `restoredFrom`，可选 `note`（不超过 300 字的改动说明）。普通保存不能删改旧版本。
- 每次主动向已关联方向提问时，只有最新保存的一版（含改动说明）进入 `researchSnapshot`；历史版本和编辑中的草稿不发送。已有附加笔记和其他研究文档仍需分别选择。
- `/记录` 只在已关联方向时开放 `update_research_notebook`，提交完整正文与一句 `summary`；浏览器在完整回答后核对原方向、记录修订、工作稿基础版本与快照摘要，再追加一版并把 `summary` 记为改动说明；同一回答幂等。已删除方向或过时回答不能覆盖新文字，AI 草稿保留在回答中可查看。
- 单版正文最多 24000 字符，最多 500 个版本，并受探索单记录 8 MiB 限制。超限保留原记录并报错。
- 模型上下文仍使用现有保守预算；完整工作稿装不进本轮预算时请求明确失败，不截断后整体改写。真实模型按小节整理的质量需要实际使用观察。

## 文献交付

内容目录中的 `readingAssignments` 明确声明一个公开阅读集合、本次交付批次及固定的导读修订。它与导读选择一起校验、预览、导入和回滚。首次仅对唯一匹配的公开方向标题建立集合绑定，之后通过本地交付凭据继续关联，改标题不影响已绑定集合。它不是关键词推荐或“入库时间接近就算相关”的推断。

浏览器启动或方向改变后处理尚未消费的批次，原子保存关联和凭据；手动移除后的文献不会因为刷新重新加入。遇到重名、固定版本缺失、容量不足或写入冲突时保留现状，并提示重试或手动关联。现有私人问题、摘录、阅读标记均不因交付而改写。完整格式与 Harness 操作见[按方向交付文献](../content/READING-ASSOCIATIONS.md)。
