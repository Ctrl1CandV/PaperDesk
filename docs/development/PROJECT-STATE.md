# 当前项目状态

PaperDesk 0.1.0，产品规格 1.1。书架、导读、深度阅读、研究探索、笔记与 AI 阅读功能已完成收口，后续围绕实际使用问题维护。

## 当前能力

- 14 篇当前阅读材料：4 篇综述、10 篇论文；保留 21 个导读修订、180 个单元和 166 个来源链接。
- 书架筛选 → 导读卡 → 深度阅读；保留完整段落、章节定位、原文入口、公式和必要教学图。
- 独立的导读/原文阅读标记、真实续读位置、笔记、研究问题、证据、下一步与主动上下文复制。
- 内容不可变修订、校验、导入、恢复与选择回滚；旧链接和个人引用保持版本身份。
- 可选 ChatGPT 或兼容 API、流式问答、原文检索、来源回放、可选联网查证与独立会话备份。
- AI SQLite 和浏览器 IndexedDB 使用增量统计、分页读取与显式兼容迁移；导读正文按需加载。固定原文与核验记录独立保存，检索索引可重建。

## 使用与数据位置

`npm run build` 后执行 `npm start`。正常来源固定为 `http://127.0.0.1:4173`，AI 服务为 4176，隔离浏览器检查使用 4174。不同来源的浏览器记录相互独立。

| 数据 | 保存位置 | 备份边界 |
|---|---|---|
| 已审核导读 | `content/` | Git 中保留全部修订 |
| 笔记、探索与阅读状态 | 浏览器 IndexedDB `paperdesk-personal-v1` | 个人记录备份 |
| AI 会话与来源快照 | `private/ai/` | AI 会话备份 |
| 固定原文、解析与核验记录 | `private/reading/` | 原文材料独立备份 |
| 本地模型配置 | `server/config.local.json` | 不进入公开仓库或会话备份 |

目录重组保留上述位置、格式、路由与 npm 使用方式。操作细节见[运行说明](OPERATIONS.md)，边界见[隐私](PRIVACY.md)。
