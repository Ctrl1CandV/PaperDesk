# 内容制作与维护

这里保存网站消费的内容契约和持续制作流程。论文正文、导读元数据、卡片和来源身份仍位于项目根目录 `content/`；本目录不保存个人阅读记录。

| 需要做什么 | 先阅读 |
|---|---|
| 理解元数据、正文和不可变修订 | [内容契约](CONTENT.md) |
| 制作导读与深读讲解 | [内容生产工作流](workflows/CONTENT-WORKFLOW.md) |
| 处理原文定位、公式与教学图 | [来源与图示](workflows/SOURCES-AND-VISUALS.md) |
| 校验、导入、恢复或回滚内容 | [内容更新](CONTENT-UPDATES.md) |
| 明确辅助发现的边界 | [辅助发现](ASSISTED-DISCOVERY.md) |
| 阅读现有公共学习路线 | [记忆与动态决策路线](LEARNING-ROUTE.md) |
| 核对依据与归属 | [参考资料](REFERENCES.md)、[导读来源](ORIENTATION-SOURCES.md)、[逐篇研究核验](../research/) |

[证据与问答示例](templates/README.md)供制作时参考。它们不是可绕过当前 schema 直接导入的内容格式。运行原文材料命令与三类备份前，先查[运行说明](../development/OPERATIONS.md)。
