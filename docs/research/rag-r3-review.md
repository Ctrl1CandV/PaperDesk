## 教学计算与语言自查

- 候选内 softmax：分数 ln3、0 → 权重0.75、0.25；仅是教学数值。
- 简单序列混合：0.7×0.4+0.3×0.8=0.52。
- 两词元例子：Sequence=0.09，Token=0.25；Token 四项0.0225、0.2025、0.0025、0.0225，合计0.25。解释包含路径限制及先验乘数次数的区别。
- 训练例子：权重各0.5、目标似然0.8/0.2，责任0.8/0.2，单样本对分数梯度为-0.3/+0.3。固定候选集合的 softmax 求导给出 `w-r`；用 Node 有限差分检查第一项导数，误差小于1e-8。
- 位置后验公式是依据 Token 结构写出的教学简式，未冒充论文新编号公式。
- 已从头通读候选正文，检查先交代背景、再任务与全貌、再机制、再证据；修正了概率表“第二列”的歧义、单样本梯度记号与 NQ 首次缩写。
- 全文26411个 Markdown 字符，约1.44万汉字；16个阅读单元，最长2591字符。检查器统计限定否定词22处，约每万字符8处；不是靠删除小样本、测试划分或不等预算条件降低密度。

## 原文问题与相对 r2 的改进

1. **人工评价冲突：**主文 §4.3 写事实性“两者都好”17%，表4写11.7%。不选择一个数字当成确定事实；正文只引用一致的胜出项，并提示存在冲突。r2 已保留缺口，本轮继续保留。
2. **附录 G：**原文把包含冻结文档编码器的总量称为626M trainable parameters，同时承认不训练文档编码器；还写出728维向量。未核源码以解决这些表述，正文只采用主文的 BART 约400M，不采用精确总可训练参数、向量维度或据此计算的存储规模。
3. **分类实现：**r2 主要依据单输出词元说明等价性。本轮加入附录 E 的重新生成声明与分类头步骤，避免将简化模型定义误当成完整实现。
4. **预算与划分：**加入附录 A 的15/50篇与解码设置，明确模型比较同时改变预算；加入附录 D，展开 TQA 双测试列，不把68.0与57.9直接比较。
5. **原图与机制：**用原图1–3代替旧教学流程图；加上候选内归一化、K×V概率表、两词元数值展开、固定候选梯度解释和解码候选补算；篇幅从概要改为连续机制讲解。
6. **来源版本：**补充文件是同会议条目的官方附件，不构成固定正文改版。元数据 `source.url`、`source.version` 原样继承 r2。
