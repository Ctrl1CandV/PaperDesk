## 差异、边界与未验证项

- r1 已给出主要结果，本版保留其固定来源和语义对应的单元 ID，增写图 1 逐步解说、两种回退条件、图 3 和具体实验对照；未原位修改 r1。
- 旧版 WebShop 写“500 条测试指令上给出的成功率为……Act 30.1%”；保持原表口径，不把它换算成整数任务数。
- 论文摘要将 ALFWorld 相对模仿学习的提升写为 34 个百分点，这对应最好 ReAct 71 与表中 BUTLER 37 的比较，并非六组平均与基线的差。本版展示两者而不把该差值写成平均增益。
- 青榆站和投票例子为自编；没有实验复现，没有核对附录全部轨迹或被引工作的全文。表格数值与原文对照不代表结果可复现。
- 本次为作者自核，未有独立审阅者从原文重新审核；也没有实际页面渲染或读者验收。工作流的临时校验仅检查结构，不能替代这些工作。
