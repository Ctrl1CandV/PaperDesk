# Agent 与模型评测：选文、提取与作者核查

日期：2026-10-30。本文记录 AI 作者的来源获取、分型提取与自审；不是人工审阅、独立内容审阅或实验复现。独立整合审阅、正式导入与实际页面检查由集成环节另行记录。原文材料保存在项目忽略的 `.source-review/research-refresh/evaluation/`，候选包在 `incoming/research-refresh/evaluation/`。没有读取个人记录或改动已发布旧修订。

## 选文与分工

评测学习组采用两篇综述和三篇论文：保留已有 HELM r2，新增 LLM Evaluation Survey、Agent Evaluation Survey、AgentBench、τ-bench。两篇综述分别组织模型能力评价和连续行动系统评价；HELM 解释场景、适配与指标；AgentBench 展示跨环境协议、分项分数与终止诊断；τ-bench 补上用户互动、领域规则、终点判据与重复成功。选择 τ-bench 而非再加一个网页基准，是为了让这组内容覆盖更不同的评价问题，而不是只增加环境数量。

本轮没有重新审计 HELM 原文与既有正文，沿用它的已记录覆盖边界。新增材料均为 `mode: standard`、`coverage.scope: mainline`、`basis: sections`；两篇综述不宣称 full-survey。采用固定历史版本，是为保存明确可核对的材料身份，不表示这些版本覆盖最新进展。未来问题只作为当时作者的判断，不能直接移植为当前研究空白。
