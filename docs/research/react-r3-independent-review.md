- **表 1 与混合策略：**固定原文第 5 页七行提示结果、21 条和温度 0.7、HotpotQA/FEVER 的 7/5 步、最高票严格少于 n/2 的条件均与正文一致。原表另有监督式 SOTA 行，正文作为主要提示策略摘录而未列出，不构成数字错误。五票例子算术正确；恰好一半不触发回退的说明与原文条件一致。
- **表 2：**第 6 页说明各方法正确及错误各 50 条，共 200 条；正文的 94/6、86/14、47/23/29、16/56/28 和 ReAct 错误组幻觉 0 与原表一致，分母及取整条件已说明。分类文字的范围问题见上表。
