## 发现的原文问题与与旧稿的出入

1. **表 7 行数与正文不符。** 正文 p13 写“13 个”，表 7（p14）列 16 行。导读按行数写，并在正文与覆盖说明中各标注一次。
2. **API-Bank 规模与原文摘要不同。** 综述记 53 API / 264 对话 / 568 调用；arXiv 2304.08244 摘要为 73 个 API 工具 / 314 段对话 / 753 次调用。两套数字对应不同手稿，导读保留综述记法并注明差异。
3. **§3.3 末尾段落错置。** 社会科学一节的最后一段谈“single-task systems”“interactive medical systems”与临床需求，与本节内容不衔接，疑似医学节总结被并入。导读正文指出该段可跳过，未据其改写任何结论。
4. **医学教育一句方向颠倒。** p11 关于 Lyu 等人的叙述写着 “the quality of ChatGPT has shown improvement compared to GPT-4”，与同段前文（先测 ChatGPT、后测 GPT-4）相反。导读未采用该句结论。
5. **基准命名不一致。** 综述写作 SOCKET（表 7 与 §4.2），其引用的 arXiv 2305.14938 标题为 SocKET。导读正文沿用综述写法，术语卡列出两个名称。
6. **表 7 的“Domain”列与内容不完全匹配。** Big-Bench 与 HuggingFace Leaderboard 被归为“特定下游任务”，与其覆盖面不符。导读把它作为“作者的一种划法”讨论，未修改原表。
7. **与旧导读（r1）的出入。** r1 为 8 个单元（开篇加 7 节）、约 3 500 字，主要按“能力—场景—风险—基准—评分—动态”概述，未使用图 1–3，未给出具体数字，也未记录下面这些问题。r2 重写为 13 个单元，新增图 1–3、表 7 与表 8 的重排、要点覆盖率手算，以及逐条数字核对；旧稿中“HELM 值得配合阅读”一条保留为编辑阅读顺序，未继承其无出处的概括（例如早期的“数百篇研究”改为按原文可核的 16 个基准与 §4 的叙述）。
8. **旧稿保留的边界照旧成立。** v1 与 2024 年 ACM 正式版未逐段比较；两版不混用；历史结果不是当前排名。
