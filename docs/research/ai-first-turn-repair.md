# AI首问与实际答疑检查 · 2026-11-03

## 发现与修复

默认32768本地预算、3000输出预留、无历史和无研究方向时，公开 `llm-survey` 的后训练章节可以复现首问413。整篇元数据约10623 UTF-8字节（引用约4570、阅读引导约3793、覆盖约1831），与系统提示、工具声明、包装和后续资料预留叠加后，前置正文额度为零。这不是模型真实使用量，也不是已连接账号的聊天历史耗尽。

初始元数据改为当前所选章节的阅读目标和链接出处，保留完整论文身份、书目、覆盖限制，并明确记录省略范围。关闭工具时不再计入工具声明。默认模型预算没有提高，最终适配器请求预算检查仍保留；超大问题仍拒绝发送。

实际连接测试进一步暴露两处接口问题：授权准备与模型目录共用15秒总限时；工具带可选参数却强行启用 `strict:true`。前者改为分别有界的30秒阶段、继续服从原总限时，保留登录及旋转续期持久化；后者按[官方工具契约](https://developers.openai.com/api/docs/guides/function-calling)显式采用与现有可选参数兼容的非严格工具模式，并保留本地参数及权限校验。

代码检查还发现两个适配器的工具参数限制仍为旧2000字符，无法承载完整工作稿。研究写入工具现与已保存契约统一为40000字符；只读工具仍2000。工具成功后的提示改为简述工作稿变化，不重复完整正文。UI对尚未accepted的HTTP413/504等失败保留问题、移除临时空回答；已accepted后的中断仍保留部分答案。
