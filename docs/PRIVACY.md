Do not add sample identity fields, analytics, personal screenshots or environment inventories. Tests use clearly synthetic text and records, never a copy of the operator's real notes.

The developer works only from this standalone input. Do not inspect parent/home folders, other projects, global memories, account configuration or shell history to fill gaps. Do not read sensitive originals first and attempt to sanitize them afterward. Do not include absolute machine paths in output artifacts or copied reading context; use project-relative artifact paths and relative application routes.

No private data is sent to a model or service by the product. Copy/export actions have an exact preview or a clear local-download action; reading an external source is deliberate. Credentials and personal records remain outside source packages and Git. No Git identity setup, commit, push or publication is authorized by this handoff.

These instructions govern the project; they cannot prevent a host from automatically attaching account or machine context before the developer reads them. Host configuration and filesystem isolation must be arranged by the operator separately. A file audit is not a guarantee about account behavior or automatic context.
