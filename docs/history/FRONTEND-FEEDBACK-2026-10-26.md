# 前端反馈迭代记录 — 2026-10-26

产品规范仍为 1.1。本记录承接前端重构后的实际界面反馈，保留最终设计决定、参考依据和验证边界；初始重构见 [前端重构记录](FRONTEND-REFACTOR-2026-10-26.md)。不保存会话原文、个人截图、账户状态或机器信息。

## 本轮需要解决的关系

| 观察到的问题 | 本轮决定 | 检查重点 |
| --- | --- | --- |
| 大窗口中工作区占比偏低，目录、导读和 AI 均过窄 | 提高整体可用宽度，分别分配列表、详情、目录、正文和对话的空间；正文行长与工作区宽度分别处理 | 宽屏有效占用、长标题断行、侧栏可读性；中小窗口仍可操作 |
| 书架条目与底色接近，选文边界不明确 | 浅灰工作背景与白色条目形成明确表面差异，选中态另有强调 | 普通、悬停、选中和键盘焦点都能辨认 |
| 导读的重要信息藏在多组折叠项中，展开后变成漫长、松散的堆叠 | 概述、阅读重点、准备、覆盖边界和章节入口直接呈现；较宽详情中并列准备与覆盖，章节按可用宽度分列；完整作者与来源单独查看 | 首屏能判断文章作用，关键条件无需逐个展开，长作者列表不挤占阅读入口 |
| 引用占据较多横向空间，侧栏底部的独立卡片过于突兀 | 引用采用紧凑但仍可识别原文与定位的样式；章节操作融入目录所在区域，降低独立卡片分量 | 来源身份与定位不丢失，链接焦点和返回有效，工具不遮挡正文 |
| AI 材料说明与对话各自滚动，说明分散且难懂 | 面板仅保留简短材料入口，完整发送范围放入明确的材料对话框；当前问题材料与当前阅读位置仍分别保存 | 发问后换章不改旧问题依据；材料说明不会挤掉对话；长回答滚动稳定 |
| AI 连接、联网、恢复及模型按钮散落，设置缺少共同秩序 | 输入区合并模型连接与联网摘要；设置统一容器与字段对齐，按 ChatGPT、API、联网查证分区；连接状态与恢复动作成组，主要保存/连接动作集中且加宽 | 未连接、已连接、额度限制、待授权、保存与错误的组合状态；输入保留和键盘操作 |

以上调整复用已审定导读内容、来源定位及现有业务关系，不因排版重写研究结论。原论文版本、导读修订、显式阅读记录继续分别表达。

## 为联网配置补齐的能力边界

联网开关移入设置，并与模型连接共用一个入口。新增 Tavily 密钥保存端点，仍由本机后端持有密钥；页面只读取是否已配置。保存密钥和允许联网是两个明确动作，保存本身不发送检索或推理请求，也不切换模型提供方。

联网权限用于当前导读的后续提问，随每次实际请求固定。材料说明保留数据去向：检索词可包含提问内容，发送到 Tavily；得到的网页摘录发送给模型。它不是浏览器全局偏好或后台自动检索许可。

静态审查覆盖 `src/assistant/api.ts`、`server/settings.mjs`、`server/http.mjs`，并追踪配置标准化、运行时更新、设置表单及检索调用。审查时未发现需要修复的密钥回传、跨站保存、旧版本覆盖或保存即开启联网的问题：新端点沿用 Host/Origin/token 检查、严格字段校验、配置修订与文件指纹、活动请求互斥、原子替换及读回确认；Tavily 目标地址固定且拒绝重定向。模型 API 地址变更仍要求重新输入对应密钥。该结论是代码审查，不替代运行验证。

## 最终空间与画面

工作区先加宽以恢复侧栏和导读可读性，再按实际反馈回收过大的铺展。阅读区保留三栏及独立正文行长；书架在最后一次修订中单独再收窄约 15%，论文列表和信息卡保持原来的相对比例。

| CSS 视口 | 最终书架宽度 | 阅读工作区宽度 | 阅读目录／正文／AI |
| --- | --- | --- | --- |
| 1440px | 1122px | 1320px | 约 223／593／386px |
| 1920px | 1428px | 1680px | 约 284／750／491px |
| 2560px | 1632px | 1920px | 约 322／832／558px |

这些有效宽度不含外围留白；阅读工作区包含目录、正文面、AI 和列间距。书架在至少 1200px 的视口使用均衡工作区的 85%，最大 1632px；更小窗口保留可用宽度及既有重排。正文上限仍为 832px，关闭 AI 仍保留正文宽度与位置。笔记、探索和备份沿用各自较小的上限，不跟随最后的书架缩小。

最终实际查看了 1920px 书架、1920／1440px 选中导读：两侧留白更充分，关键选择依据仍直接可见，较窄导读内的准备与覆盖区域自然转为顺序排列。最终公共内容画面保存为 [书架](../images/library.png) 和 [导读](../images/orientation.png)。

本轮此前还实际查看了 1440／1920／2560px 阅读、1920px 正文中段、1150px 中间布局、390／320px 阅读及最大字号、图示和 HELM 表格，以及笔记、探索和备份。AI 看图覆盖空闲、长回答、已连接、额度限制、API、联网及窄屏设置。生成但未实际打开的其他图片不作为视觉结论；所有窄屏检查均为模拟视口，不是实体手机。

局部过程证据保留在忽略目录 `.cache/feedback-round/`：`before/`、`after/` 对照首轮改动，`before-width-balance/` 和 `width-balance/` 记录上一次比例回收。最终书架的测试截图位于 `docs/evidence/library-dual-*.png`，属于可重建本地产物。阅读基线捕获时 AI 同组修改已开始，因此仅用于对比阅读区域几何，不宣称整张 AI 区都是旧版基线。

## 验证与修复

最终提交前检查：

- `npm run build -- --logLevel warn`：内容校验、TypeScript、生产构建通过；保留既有超过 500 kB 的打包警告。
- `node --test --test-reporter=dot tests/*.test.mjs`：通过；dot 输出没有总数，不另行推定测试数量。
- `npx playwright test`：125 项通过，覆盖书架、阅读、来源返回、导航历史、笔记／探索、备份以及合成 AI／设置状态。
- 已查看上述最终书架画面；前面记录的阅读和组合设置状态也曾实际查看。构建、浏览器断言与看图分别构成证据，不能互相替代。

过程中发现并修复了来源弹窗的 Escape 冒泡误关导读、筛选后延迟焦点恢复抢走新键盘操作、桌面 AI 转模态时遮挡已打开设置／资料弹窗等问题。实际看图还发现完整引用标签的隐藏样式只在书架作用域生效，导致阅读正文同时显示紧凑和完整标签；移到共享样式后只显示紧凑标签，完整可访问名称和来源弹窗仍保留。已有引用测试增加了显示宽度检查。

较早一次 125 项浏览器运行中有 108 项通过、17 项旧引用文字断言失败；改为核对完整可访问标签后，相关 20 项复查通过。最后重新执行的完整 125 项运行全部通过。没有把分次结果拼成一次全量通过，也没有因紧凑显示删除正文保真检查。联网配置另有 23 项专项单元检查通过记录。

审定导读、来源、研究条件和覆盖缺口未因排版重写；个人记录格式与既有保存、冲突和备份边界保持不变。

## 服务与验证边界

浏览器检查使用独立来源、公共导读和合成记录。AI 成功、失败、历史、额度限制、保存冲突及授权等待均为标明的合成状态；测试防护或请求拦截阻止其代理到正常 AI 后端。未读取真实密钥、私有对话或笔记，未执行真实授权、推理或 Tavily 检索。原文 PDF 实际锚点、原生浏览器缩放、其他引擎、屏幕阅读器及实体手机仍未验证。

新增检索配置接口需要现有本机服务重启一次以加载：在原启动终端停止旧服务，再运行 `npm start`。前端生产产物已构建；后续仅改前端时重新构建并刷新页面即可。配置保存后即时生效，但是否联网仍由读者明确开启。提交和推送按项目 Git 约定执行；部署与发布仍是独立范围。
