## 2. 改动与兼容

AI SQLite 使用 layout 2：增量 bytes/reservation 统计、索引游标分页和 compact turn summaries，完整依据按单轮读取。默认逻辑容量 512 MiB、低盘保护 32 MiB；旧 16 MiB 仅保留为旧 JSON 传输上限。新 AI v3 NDJSON 从一致 SQLite 快照导出，先在独立数据库暂存并校验，再一次事务导入；兼容旧 v1/v2 JSON，保留 provider/fallback 与旧 L/W 来源，新 O 来源不冒充旧导读原文。

浏览器保留数据库名 `paperdesk-personal-v1`，升级 IDB layout 2，新增索引、增量容量、升级前副本和备份暂存。普通续读/笔记写入不全库扫描。个人记录默认 512 MiB，旧 v1 JSON 仍为 5 MiB，新 v2 archive 逐块验证并原子合并，保留既有冲突与相关笔记引用语义。新格式不能被旧程序直接读取。

原文使用独立 `materials/manifests/derived/evidence` 权威文件与可重建 FTS5 索引。三份可检索材料为 618 units；额外两份实际核图 PDF 使用 `referenceOnly`，保存与备份但不参与候选竞争。版本/用途、目录、解析与核验映射固定到索引代次。实际材料备份含 21 文件、21,575,992 字节；恢复到新目录后重建索引，6 条证据的 15 个原文绑定与导读 metadata/工具返回均读取成功。

旧 18 修订的 36 个 metadata/正文文件 SHA-256 与起点一致；当前共有 14 篇推荐导读、21 个保留修订。新内容仍用稳定 unit ID，打开、生成或导入不自动改变阅读标记。
