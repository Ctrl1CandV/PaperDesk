# 确认单：书架简化与导图汇报页

日期：2026-11-19　状态：已确认（2026-11-19）

## 一句话目标

书架首页回到一个干净的列表；组会汇报页以一张可逐层展开的思维导图为主，用 10–12 分钟简洁讲清一篇论文的价值，下方只留备查讲稿。

## 项目档位
- 规模：一次会话内完成（书架一页、汇报页一页、一份汇报稿内容）。
- 寿命：长期迭代的个人阅读工作区。
- 交给谁：自己使用；汇报页在组会上投影给导师和同学看。
- 验证档位：长期迭代。现有自动化测试保持通过，改动处补回归测试；页面实际截图查看。

## 使用者与任务
- 书架：自己进来找一篇导读继续读，或按主题找一组文章。
- 汇报页：组会上 10–15 分钟讲一篇论文。导师要的是简洁讲清整篇论文的价值，用思维导图辅助，而不是长而细的逐页讲解。讲者边讲边点开导图分支；导师能一直看到全局结构和当前讲到哪里。

## 倾向
- 想要：书架“看起来不复杂”；汇报以导图为主体，概览里那种大导图的效果；先主干、讲到哪展开到哪。
- 不要：书架上的主题分组、分组统计（篇数、综述/论文数、导读已读进度）和右上角“探索 ↗”；汇报页里 PPT 式的“开始讲述”全屏逐页模式。

## 功能与架构
- 做：
  - 书架：18 篇按原书架顺序排成一个列表；搜索框输入类别词（如“基础”“通信”“评价”及集合名中的词）能筛出对应一组；保留搜索、全部/综述/论文、阅读状态筛选和信息卡。
  - 汇报页首屏：一张占满可用视口的大导图。开场只显示论文和各部分分支；点部分展开它的讲解点，点讲解点展开关键词，并在导图旁显示这一点的一句话结论、原图（如有）和出处。提供“全部展开 / 收起”和“全屏”（只放大导图，不翻页）。
  - 汇报页下方：精简后的逐点讲稿，备查用；保留“导读原文”对话框、“讲稿提示”和“打印讲义”。
  - 汇报稿内容：通信综述压缩为 3 个分支、约 7 个讲解点加收束，按 12 分钟安排。
- 不做：PPT 式讲述模式（逐页翻页、计时条、O/N 快捷键）；探索页、笔记页、阅读页改动；AI 功能改动。
- 数据：汇报稿仍是绑定导读修订版的内容文件（`content/presentations/*.json`），只引用该修订版已有的章节、图和出处，校验脚本照旧检查。阅读状态只来自读者自己的标记。
- 运行与部署：本地 `npm start`，不部署。

## 内容与展示
- 书架首页自上而下：标题与“上次停留”、一行工具（搜索、类型、阅读状态）、一个列表。不再有分组标题和分组统计。
- 汇报页首屏：标题一行与少量操作 → 大导图（主体）→ 选中讲解点时在导图旁出现的简短卡片。
- 往下：一句话主张 + 逐点讲稿（每点：一句结论、关键词、图或表、出处、可选讲稿提示）。

## 审美
- 风格与参考：沿用当前汇报页概览导图的样子（markmap 式彩色分支、标签写在分支上）；展开与收起带位置过渡；整体沿用 PaperDesk 现有字体与配色。
- 精致程度：投影可读——导图标签在 1440×900 下不小于 15px，主干与分支一眼可辨。
- 交给：frontend-craft。

## 假设与“你定”的选择
- 选中讲解点时在导图旁显示简短卡片（一句结论 + 原图 + 出处）：图是讲清价值的主要证据，只靠口头说不清；卡片可关闭，不遮挡导图主干。
- 书架类别词复用现有三个公共阅读集合（基础 / 通信 / 评价），集合不再显示为分组。
- 汇报稿精简：删掉“背景与定义”“架构分布表”“范式”“对象”这几个细节点（它们已在七维度表里）；“评价缺口”和“开放问题”并入收束，讲“价值与边界”。
- 全屏使用浏览器全屏接口，只作用于导图区域。
- 实现中调整（2026-11-19）：A5 的“所有节点可见”改为“所有分支和讲解点可见”。关键词只跟着当前讲解点展开：三个分支的关键词全部画出时，1440×900 下标签只有约 8px，投影读不清。打印讲义里的导图仍完整画出关键词。
